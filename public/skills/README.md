# Skill logo assets

These assets are stored locally so the portfolio remains standalone. Brand
marks are used only beside the matching skill name and are not endorsements.
Keep their proportions and colors intact.

- `teamcity.svg`: TeamCity product mark; source reference:
  https://www.jetbrains.com/company/brand/
- `mixpanel.svg`: Mixpanel mark; source reference:
  https://brand.mixpanel.com/
- `cursor.svg`: Cursor mark; source reference:
  https://cursor.com/en-US/brand
- `claude.svg`: Claude mark; source reference:
  https://www.anthropic.com/news
- `gemini.svg`: Google Gemini mark; source reference:
  https://gemini.google.com/
- `openai.svg`: OpenAI Blossom geometry from the official brand download;
  source reference: https://openai.com/brand/
- `pwa.svg`: community-adopted PWA logo (CC0); source reference:
  https://github.com/webmaxru/progressive-web-apps-logo
- `redux-saga.svg`: Redux-Saga project mark; source reference:
  https://github.com/redux-saga/redux-saga/tree/main/logo

RTK Query reuses the Redux mark because it is part of Redux Toolkit. Codex
reuses the unmodified OpenAI mark because no separate public Codex brand pack
is available and the adjacent label identifies the service.

`websockets.svg`, `rest-api.svg`, `monorepo.svg`, `microservices.svg`, and
`agile.svg` are original neutral glyphs for concepts that do not have a single
canonical brand. Do not replace them with unrelated vendor logos.
