# Experience background assets

These locally hosted WebP images keep the portfolio standalone while making
each employer domain recognizable at a glance.

- `hospitality-reservations.webp` — restaurant service, diners, table layout,
  and a reservation floor-plan interface.
- `global-fashion-commerce.webp` — apparel retail, product browsing,
  fulfilment, and global commerce.

Both assets were generated with the built-in image generation tool on
2026-08-19, then resized to 1920px and compressed to WebP. They intentionally
contain no company logos, readable text, or trademarks; the official employer
logos remain separate HTML image assets.

Design guidance: use these only as atmospheric backgrounds beneath strong
contrast overlays. Do not place essential information inside the bitmap.
